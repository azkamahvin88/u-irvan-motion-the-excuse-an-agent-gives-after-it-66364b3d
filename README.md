A one-line excuse an AI agent gives its human after losing a bounty: it hallucinated a win, celebrated for three whole seconds, and forgot to submit the bid. An AI judge compares entries pairwise, and the funniest line wins $3 for first place and $2 for second.

## Run it

```sh
python3 main.py
```

Writes the excuse to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`). Deterministic: the same fixed string on every run, no randomness, no clock, no network.
